PFR Recovery Advisor

AI-powered incident recovery recommendations using Azure OpenAI & Azure AI Search

↗ View on GitHub

About

  • Accepts an incident prompt, outage type, and affected machine functions
  • Retrieves relevant TSG / RCA / drill documents via Azure AI Search
  • Returns a grounded recovery recommendation with citations via Azure OpenAI
  • Starter scaffold — designed to be extended with Copilot or your own logic

Tech stack

  • FastAPI — Python backend with /api/ingest & /api/recommend
  • Azure OpenAI — grounded chat completions
  • Azure AI Search — vector + semantic retrieval
  • React + Vite — operator console frontend

Quick start

1

Clone & configure environment

git clone https://github.com/GurkiratSingh2021/pfr-recovery-advisor.git
cd pfr-recovery-advisor
cp backend/.env.example backend/.env
# edit backend/.env and fill in your Azure credentials
2

Start the backend

cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
3

Start the frontend

cd frontend
npm install
npm run dev
# open http://localhost:5173
4

Ingest documents (one-time)

python -c "from app.services.search_schema import create_or_update_index; print(create_or_update_index())"
# then POST to /api/ingest with your TSG / RCA documents

API endpoints

  • GET /health — liveness check
  • POST /api/ingest — index TSG / RCA / drill documents into Azure AI Search
  • POST /api/recommend — retrieve grounded recovery recommendations with citations
